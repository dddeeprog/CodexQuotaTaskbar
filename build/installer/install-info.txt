Codex 额度岛 · 安装说明

本安装版支持 Windows 10（1809 及以上）/ Windows 11 x64，已内置 .NET Desktop Runtime。

默认仅为当前用户安装，不需要管理员权限。安装目录可选择；建议保持默认目录，以便自动更新。

使用前请在 Codex 桌面应用或 Codex CLI 中通过 ChatGPT 登录。可选的网页登录订阅功能另需 Microsoft WebView2 Runtime；未安装时，应用会提供微软下载入口，普通额度显示不受影响。

如果正在运行便携版或旧版本，请先从额度岛右键菜单选择“退出额度岛”。安装不会删除原便携文件，也不会删除已有设置或网页登录资料。

开始菜单快捷方式会自动创建，桌面快捷方式可选。开机启动仍由应用内开关控制，安装程序不会擅自开启。

卸载会移除程序、快捷方式及指向本安装路径的开机启动项，保留设置和独立网页登录资料；不会退出或清理 Codex 桌面应用。

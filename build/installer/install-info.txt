点岛 · 安装说明

本安装版支持 Windows 10（1809 及以上）/ Windows 11 x64，已内置 .NET Desktop Runtime。

默认仅为当前用户安装，不需要管理员权限。安装目录可选择；建议保持默认目录，以便自动更新。

使用前请在 Codex 桌面应用或 Codex CLI 中通过 ChatGPT 登录。可选的网页登录订阅功能另需 Microsoft WebView2 Runtime；未安装时，应用会提供微软下载入口，普通额度显示不受影响。

如果正在运行便携版或旧版本，请先从点岛右键菜单选择“退出点岛”。安装不会删除原便携文件，也不会删除已有设置或网页登录资料。

开始菜单快捷方式会自动创建，桌面快捷方式可选。开机启动仍由应用内开关控制，安装程序不会擅自开启。

BongoCat 外观使用单独许可的 Live2D Cubism Core 渲染组件，基础安装包不包含该组件。交互式安装期间会展示 Core 专用条款及官方许可原文，只有明确同意后才从本项目 GitHub Release 下载约 2 MB 的固定模型渲染组件，并校验后安装。拒绝或关闭确认时不下载，仍可使用小白球及点岛其他功能；静默安装不会代替用户确认。便携版可在外观菜单主动确认后下载；升级沿用仍有效的选择和已校验缓存，不删除设置、消息或草稿。

全新安装同意 Core 后使用预设外观：一体面板、白球与 BongoCat 共存、材质透明度 3%、显示全部任务栏、隐藏托盘图标、开启自动更新和订阅详情。已有配置原样保留；Dot 实时接收、键鼠互动和开机启动仍需单独开启，不随条款同意自动开启。

点岛主体按 GPL-3.0 提供，对 Core 的限制不适用于独立的 GPL 主体及其他开源组件。各组件声明见随程序提供的 THIRD_PARTY_NOTICES.md；对应源码入口为 https://github.com/dddeeprog/CodexQuotaTaskbar 。

卸载会移除程序、快捷方式及指向本安装路径的开机启动项，保留设置和独立网页登录资料；不会退出或清理 Codex 桌面应用。

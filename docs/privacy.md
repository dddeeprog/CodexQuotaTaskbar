# 隐私与数据说明

点岛（CodexQuotaTaskbar）是本机独立运行的额度浮层。额度、订阅计划与额外点数来自本机官方 Codex App Server；额外点数使用额度响应中的 `credits.balance`。本说明中的增强读取仅用于详情页的“订阅有效至”。

## 订阅有效期读取范围

“订阅有效期”默认开启，可从托盘菜单关闭。开启时，专用只读组件查找 `CODEX_HOME/auth.json`；未设置 `CODEX_HOME` 时，查找用户目录下的 `.codex/auth.json`。它只提取 `tokens.id_token`、`tokens.access_token` 和当前账号的 `tokens.account_id`，不提取 `refresh_token` 字段。读取有文件大小上限，不接受指向其他文件的重解析点。

应用先解析 ID 令牌或访问令牌中 `https://api.openai.com/auth` 下的 `chatgpt_subscription_active_until` 字段。该字段只用于展示订阅日期，不把令牌本身的 `exp` 当作订阅到期时间。本地结果的更新时间对应登录文件修改时间。

本地字段缺失或日期已过期时，应用才使用现有访问令牌，向固定的 `chatgpt.com` HTTPS 主机发送只读 GET 请求：

- `/backend-api/accounts/check/v4-2023-04-27`：匹配当前账号，读取订阅权益的有效截止时间。
- `/backend-api/subscriptions`：在需要时按当前账号补全 `active_until` 或 `expires_at`。

在线查询会携带访问令牌及必要的账号标识，不上传会话正文。客户端不跟随 HTTP 重定向，并设置超时和响应大小上限。多账号响应按当前账号匹配，不将另一个账号或工作区的订阅日期用于当前账号。在线结果的更新时间对应本次查询时间。

## 凭据与失败处理

原有本机读取组件的凭据仅在当前进程内存中临时使用，不另存、不写回登录文件、不写入日志。该组件不会主动刷新令牌，也不会读取其他浏览器 Cookie、系统密钥环或其他进程内存。关闭“订阅有效期”后不再发起新的增强读取，并关闭网页登录窗口；已进行的原有 HTTP 查询最多等待 12 秒结束且结果不再显示。官方 App Server 的额度、计划和点数读取继续运行。

## 可见网页登录窗口

详情页“网页登录 · 更新订阅日期”或托盘“网页登录订阅”打开独立的 Microsoft WebView2 窗口。此操作会开启订阅有效期读取；不在后台偷偷打开浏览器或自动完成验证。用户自行在官方网页输入登录信息、完成验证码或其他验证，再点击“已登录，读取订阅”。Google 等身份提供商可能禁止内嵌浏览器登录；本程序不伪造浏览器或绕过限制，也不保证验证后私有接口一定可用。

浏览器使用独立的 `%LOCALAPPDATA%\CodexQuotaTaskbar\WebView2` 目录，网页登录状态和 Cookie 会按 WebView2 的正常行为保存在本机，不导入其他浏览器的数据。关闭密码保存、自动填充、原生主机对象、下载和网页权限请求。网页登录页自身可能正常维护或续期它的登录状态。

订阅读取脚本只在 `https://chatgpt.com` 执行，通过同源 `/api/auth/session` 获取浏览器会话，然后向上述固定订阅接口发送只读请求。访问令牌仅留在网页脚本内，不回传原生应用；跨进程消息只传请求标识、固定状态码、当前账号标识和订阅日期。脚本有 20 秒总超时、单响应 1 MiB 上限，拒绝重定向。必须匹配当前 Codex 账号，且写入前再次确认没有切换账号。

只有账号标识、订阅有效日期和读取时间会写入 `%LOCALAPPDATA%\CodexQuotaTaskbar\subscription-web.json`。有效日期按账号隔离，超过 3 分钟标为缓存，已过期的日期不采用；网页登录不会每 3 分钟自动刷新，需再次在可见窗口读取。详情页标注来源“ChatGPT 网页登录”。“清除网页登录”清除此应用独立浏览器资料及网页订阅缓存，不退出 Codex 或常用浏览器。

发行包仍自带 .NET；WebView2 Runtime 是单独组件。缺少它时窗口提供微软官方下载入口，点岛仍可继续运行。

这些 ChatGPT 订阅接口属于私有接口，可能调整或停止返回有关字段。仅使用系统密钥环保存登录信息、登录过期、网络失败或服务端没有披露日期时，有效期可能显示未提供或暂不可用。HTTP 401 显示“登录已失效”，HTTP 403（包括网页验证拦截）显示“服务拒绝查询”。该失败不会阻断额度刷新；若仍保留上次有效期，界面会标明缓存，不能把缓存视为最新查询结果。

“订阅有效至”表示当前信息源披露的订阅有效截止时间，不保证订阅在该日取消。自动续费、账号切换和登录信息更新时间都可能影响结果；额度重置时间与重置券到期时间不会用于代替它。应用不展示邮箱或账号 ID。

## Dot 实时消息

此功能需手动启用，启动参数 `--dot-realtime` 也会开启并保存设置。通过独立子进程中的 WebView2 打开固定官方 `https://chatgpt.com/dots/home`，复用本应用的 WebView2 登录资料，不导入常用浏览器 Cookie，不读取或导出网页令牌，不连接未验证的私有接口。该网页登录账号不自动等同于 Codex 登录账号。

连接后每 2 秒从页面 DOM 读取最近最多 12 条消息，每条最多 8000 字符；只提醒连接之后带时间的助手消息，去重标识最多保留 128 个。桥接只在上述精确官方页面执行；正文按纯文本展示，不执行消息内指令。内嵌模式在应用私有目录 `dot-unread.json` 保存最多64条收到的消息、未读标识及较早未读计数，以便重启后保留提醒；不是完整聊天历史。每条展示文本最多8000字符；64条文本窗口之外的较早未读保留计数及有限标识，不保存其完整正文，也不自动标记已读。官方网页仍会按其正常行为保存会话及登录资料。诊断不记录消息或草稿正文。

当前产品只提供消息提醒，不构造回复框或发送入口，也不自动提交或重发消息。已有未发送草稿、选区和待确认尝试按原状态机制保留或核对；移除入口不是删除、回填草稿或判定发送失败的操作。官方网页仍按其正常行为保存会话与登录资料；需要登录/验证时由用户主动打开，不绕过验证。

新消息在同一面板顶部临时向上延伸一条紧凑提醒行，约10秒后收回并保留未读标记；超时不算已读，也不替换任务、额度或角色。新提醒不激活窗口或抢键盘焦点。猫头感叹号只在本机累计提醒大于零时显示，悬浮文字仅含计数及清除提示，不展示完整消息正文。

用户点击感叹号是明确的本机批量清提醒操作：以点击瞬间的消息标识/水位确认当时已有的提醒，随后新到消息继续累计，不删除历史消息。该确认通过现有会话、token和sequence校验，状态持久化，重启不把已确认旧提醒再累加；不把自动弹出、计时收回或仅收到消息视为用户阅读，也不声称可靠同步 Dot 网页的已读状态。

父子进程通过继承的双向管道传递有界消息状态及兼容旧状态所需数据，不开放本机网络端口，不将正文写入诊断或发给额外网站。发送中断的旧尝试另保留不含正文的标识与待核对状态，重新连接不能据此自动重发。未读缓存采用有界解析及原子写入，损坏原文件在替换前保留恢复副本；不扫描其他聊天文件。

## 会话与更新

### 可选键盘敲击互动

“跟随键盘敲击”默认关闭；仅用户开启、相应互动角色可见且未减少动画时，在当前普通桌面注册 Windows Raw Input 键盘与鼠标设备类。为对应键位动作，读取固定大小 RAWKEYBOARD 的物理扫描码、扩展位和按下/松开标志；不翻译字符、不调用键盘布局或文本转换接口。鼠标仅读取左右键按下/松开标志，位置复用现有低频视线采样。不读取应用输入框、密码字段、剪贴板、前台窗口或窗口标题，不模拟、拦截或改变系统输入。

内存只保存受支持键位当前仍按住的集合及其先后关系，以及当前左右鼠标键状态；重复 keydown 不重新排序，keyup 立即移除，无键时举爪。它不是文字识别：物理键状态也可能来自用户在其他程序中的输入，因此默认关闭并可随时停用。没有按键日志、序列存储、次数统计、文件持久化或网络上传，不记录释放后的历史；输入事件不进入现有表情诊断。关闭、隐藏、锁屏、减少动画、读取失败或退出时清除状态，不恢复旧按键。

沿用有界渲染及视线采样，不为快速输入积累无界动画队列；每个按下/松开均处理，限频不丢 keyup。注册或读取异常时停止接收，不提升权限或切换为其他监听方式。不使用全局钩子、输入模拟、后台服务或新自启动项，不访问或切换安全桌面。隔离预览与合成测试不代表已经启用真实 Raw Input。

### 本地角色与 Core 组件

白球继续使用本地原生矢量绘制；BongoCat 使用固定 Live2D standard 模型，由独立本地 renderer 处理动作并返回完整像素帧。renderer 不接收账号、令牌、聊天、任务标题、窗口标题、Core对象或其他进程内存，仅接收有界的物理输入/渲染控制。渲染不引入网页或模型下载，不提供任意模型导入入口。

含 Core 的发行构建需要在使用该组件前核验仅 Core 适用的条款确认；拒绝时保留白球及其他 Host 功能。确认记录仅用于本地保存组件/条款版本或哈希、选择及必要时间，不上传账号、输入或消息内容。安装、下载或更新不自动构成新的确认；Core 确认也不会开启或改变键鼠互动开关。该共同流程仍需本次最终产物验收，本文不是既有 SDK 接受记录的批量迁移依据。

右上角表情小球使用随程序内嵌的 Grok Ball 表情配置和轮廓数据，固定提交与 MIT 许可见 `THIRD_PARTY_NOTICES.md`。现已改为 WPF 原生矢量绘制，不加载网页或 JavaScript、不启动浏览器进程、不使用浏览器资料目录，不连接 Grok 或 xAI，也不需要模型调用。旧本地试用版的 `CompanionWebView2` 目录不再使用，本次更新不自动删除它；订阅登录的 `WebView2` 目录保持不变。

小球绘制模块只接收表情编号、减少动画标记、相对鼠标方向，以及用户启用后仅在内存传递的物理键鼠即时状态；会话数量及提示文字也由 WPF 绘制。不会传入账号、令牌、会话标题或正文。表情使用本地随机洗牌轮播，不根据会话正文选择；动画引擎不会修改 Codex 数据。

会话胶囊只读本地 Codex 任务事件和名称，不上传会话正文。应用更新使用项目固定的 GitHub Release 仓库，下载后校验发布包。订阅查询与更新下载不会互相转发凭据。

## 本机项目工作台

0.1.15正式版本不提供项目工作台入口、启动协调器或快捷键；以下仅说明保留的实验源码与旧设置兼容，不表示运行时启用。

工作台只在用户手动选择的本机目录内列举、搜索和预览文件；不读取 Codex 内部数据库或聊天来推断目录，不安装桥接插件或新增会话监听。文件根目录、Git 目标目录、窗口位置和尺寸、图钉及快捷键保存在原有本机设置中。文件正文、搜索结果和提交消息不写入工作台设置或诊断；隐藏时取消读取与搜索、停止文件监听并释放预览。

文本预览和内容搜索每个文件最多 2 MiB，最多展示 500 条搜索结果；图片有独立大小与解码上限。链接及 `.git` 不作为递归文件管理入口。新建、改名和回收站操作由用户触发，不自动暂存；不能进入回收站时不退回永久删除。默认程序打开或定位会将明确选择的路径交给 Windows。

Git 操作通过本机 Git CLI 执行，显示实际仓库或 worktree 目标，提交只使用用户核对的当前暂存区；不会自动暂存、推送、拉取或修改 Git 配置。现有 hooks、签名程序和作者配置继续生效，其自身行为由仓库及本机 Git 配置决定。工作台自身不上传所选文件、diff 或提交消息，不新增浏览器进程；收起不打断已经开始的 Git 写操作，退出时等待它结束。

## 公共重置公告

应用启动时及每 15 分钟向 `https://codex-resets.com/api/v1/resets?limit=3&order=desc` 发送公开只读查询，手动刷新也可触发；再从同站 `https://codex-resets.com/api/resets?locale=zh-CN` 获取网页已有的中文译文。该第三方服务无需账号或 API key；这些请求不携带 Codex 登录信息、订阅信息、Cookie、会话内容或个人额度，只发送应用版本标识与可选的公共缓存标记。服务端仍可正常看到联网请求的 IP 地址。客户端不跟随重定向，每次请求最多 8 秒，事件响应最多 128 KiB、中文响应最多 512 KiB；两种查询分别遵守限流退避。不访问 X，不调用额外翻译服务。

仅在内存保留最近三条公告及获取时间，正文预览不超过 240 字符。中文按公告编号、时间、类型和原文核对后使用；网页中文接口不属于稳定 v1 契约，失效不影响事件刷新。中文查询失败时保留同条公告已有译文；没有可用译文则明确提示“中文译文暂不可用，以下为原文”。事件读取失败时旧消息标记缓存，首次失败显示暂不可用。公告是公共消息，不是当前账号的到账确认，不触发额度重置或领取操作。岛内保留 [Codex Resets](https://codex-resets.com/zh-CN) 来源链接，详情默认以网站快捷入口保留同一中文网站；主动点击时用默认浏览器打开。详情原历史公告列表替换为网站图标网格，不提供 X 原文入口。

已安排重置的预告独立从公开 `https://codex-resets.com/api/v1/status` 读取，不从历史、统计或概率推断。约每 60 秒发送带可选 ETag 的条件请求，尊重服务端 Retry-After，不添加破缓存参数；请求同样无账号、Cookie、会话或个人额度信息，最多 8 秒、128 KiB且不跟随重定向。只在内存保留预告标识、类型、时间、核对时间及已验证来源，不保留公告正文。连续额度上下文验证后，首次有效的未来截止时间锁定在当前进程内存；后续站点修改、缓存过期或截止已过不会直接清除锁定。底部显示倒计时，到期后显示“预计时间已到，等待额度恢复”；具体本地日期、时区、首次核对时间与来源保留在悬停提示，点击来源仅打开固定中文站点。查询失败的红色状态可暂时替代预告展示，不代表锁定已清除。未锁定的传输快照仍受3分钟新鲜度和截止检查限制，连续额度上下文或时间尚未验证时可显示“重置时间暂未知”。实际额度回升消耗当前预告，连续上下文丢失或重启会清除内存锁定；这些显示都不声称公共预告就是本账号额度到账确认。倒计时复用现有计时器按分钟更新，不在后台访问 X 或执行公告内容。

## 浮层生命周期诊断

正式程序默认在 `%LOCALAPPDATA%\CodexQuotaTaskbar\Diagnostics\overlay-<进程号>.json` 写入浮层生命周期诊断，无单独关闭开关。每个进程的快照最多保留最近128条事件，记录时间、进程号、窗口句柄、窗口实例标识、显示原因、相关进程号（前台窗口所属进程或组件渲染进程）及输入事件时间戳，用于排查浮层显示、菜单与截图遮挡问题；不记录窗口标题、消息正文、账号标识、文件路径或指针坐标，不上传。

写入在后台合并，约200毫秒后保存。128条上限只约束单个进程快照，不是整个诊断目录的总量上限；当前没有按日期或进程自动清理，也不保证退出时等待最后一次写入完成。写入失败不阻断正常操作。需要释放空间时，可在正常退出点岛后手动删除该诊断目录。

## 常用网站

详情只保存用户明确添加的网站入口，不读取或导入浏览器书签、浏览历史、账号或密码。独立配置 `%LOCALAPPDATA%\CodexQuotaTaskbar\web-shortcuts.json` 保留名称及网址，使用有大小和条目数量上限的原子写入；损坏文件保留，用户明确保存新列表前先备份。首次默认只有重置公告网站，删除后的空列表同样持久保留。只接受 http/https 地址，缺省补 HTTPS，拒绝脚本、file、凭据型地址和控制字符；点击时将已验证地址直接交给默认浏览器，不拼接 shell 命令。

添加或加载入口时，后台只读取该站点的源站根页以发现 icon/shortcut icon/apple-touch-icon，随后尝试根 favicon.ico；不会把收藏网址的路径、查询或片段发给元数据站点或第三方 favicon 服务。不执行页面脚本、HTML或网页指令，不携带 Cookie、凭据、聊天、任务、个人额度或其他收藏列表，不发送 Referer。站点声明的图标可位于其公开CDN，请求仍经过逐跳网络边界验证。采用最多2个并发请求、约8秒超时、页面256KiB和图标128KiB上限、最多3次重定向；拒绝私网/回环/链路本地等地址、危险协议、HTTPS降级和第三方favicon代理。连接时再次检查并固定已验证公网IP，不绕过系统代理或安全策略；必须使用而无法安全校验的代理路径降级为占位。

图像只接受有界PNG/JPEG/ICO并重新编码为最大64像素的静态PNG，拒绝SVG及未知类型；原页面文本仅可作为截短名称提示。小图缓存独立放在 `%LOCALAPPDATA%\CodexQuotaTaskbar\shortcut-icons`，成功缓存约7天，失败短暂缓存，来源相同的并发查询合并；异步读取和解码，不引入浏览器或高频计时器。图标无法获取、类型不支持或网络受限时，网址仍可添加和打开，仅显示域名首字母占位。已部署底部重置预告行及其来源保持不变。

用户可在添加网站时或图标右键菜单中主动选择本地图标，文件选择器仅用于此次明确选择，不扫描其他文件。只读打开所选 PNG/JPEG/ICO，最多4MiB；PNG/JPEG每边最多4096像素，ICO保持原有限制。校验文件头与可解码内容后重新编码为最大64像素PNG，保存到应用自有的 `shortcut-manual-icons`，配置仅引用生成的图标key，不保存用户原始图片路径。原图不会被修改或删除。手动图标优先于自动获取；恢复自动或删除网站在配置保存成功后，仅清理不再被任何入口引用的应用缓存文件。读取失败保留原配置并显示字母占位，不静默改写图标来源；取消选择不提交更改。没有因本地图片功能放宽网络地址检查或修改代理设置。

# Codex 额度任务栏浮层使用说明

## 启动

1. 解压 `artifacts/releases/CodexQuotaTaskbar-win-x64.zip` 到一个固定目录。
2. 双击 `CodexQuotaTaskbar.exe`。
3. 胶囊会贴在每个可识别任务栏的工作区一侧；通知区域会出现“Codex 额度”图标。

应用需要 Windows 10/11 x64，以及已使用 ChatGPT 登录的 Codex 桌面应用或 Codex CLI。正式便携包已内置 .NET 10 Desktop Runtime，新电脑无需另行安装 .NET。应用通过本机 `codex app-server --listen stdio://` 读取当前账号额度，不读取 `auth.json`、浏览器 Cookie 或令牌缓存；如果 Codex CLI 不在 `PATH` 中，会自动查找 Codex 桌面版安装包内的官方可执行文件，并复制到 `%LOCALAPPDATA%\CodexQuotaTaskbar\Runtime\Codex` 缓存后启动。这样既能使用桌面版现有的 ChatGPT 登录，也不会尝试直接执行受 Windows 商店权限保护的文件。

详情中的订阅档位采用大写额度名称：服务端返回 `prolite` 时显示 `PRO 5X`，返回 `pro` 时显示 `PRO 20X`。

## 操作

- 悬停胶囊：不再弹出系统白色提示框；额度、重置时间和数据状态请在详情卡中查看。
- 单击胶囊：打开或关闭详情卡。
- 右击胶囊或托盘图标：打开液态玻璃控制菜单，可立即刷新、检查更新、打开 Codex、切换全部任务栏/仅主任务栏、低额度提醒、自动更新、开机启动或退出。
- 将胶囊移动到桌面边缘后打开详情：详情会自动选择空间充足的一侧，并完整保持在当前屏幕可用区域内。
- 发布包、可执行文件和托盘统一使用原创“双额度轨道”图标，不使用 OpenAI 标志。
- 详情卡中按 `Esc`：关闭详情卡。

当前账号只返回一个有效额度窗口时，第二行显示 `—`，不会伪造另一个额度。

## 自动更新

- 默认开启；启动约 15 秒后检查一次，此后每 6 小时检查 `dddeeprog/CodexQuotaTaskbar` 的最新正式 Release。
- 只接受固定仓库、固定 ZIP 文件名和高于当前版本的正式版。
- 下载完成后校验 GitHub SHA-256、压缩包单文件结构和 EXE 文件头；全部通过后才退出当前实例、原位替换并重新启动。
- 更新失败时保留当前版本，后台模式稍后重试，手动检查会显示通知。

## 状态说明

- 冷青色：剩余不少于 30%。
- 琥珀色：剩余 10%–29%。
- 红色：剩余低于 10%。
- 中性占位：未登录、当前认证方式无 ChatGPT 额度、协议暂不可用或该行没有数据。
- 降低饱和度：连接中断，正在显示最后一次有效额度。

## 与 Windhawk 共存

应用是独立的任务栏贴边浮层，不注入 Explorer、不修改任务栏 XAML，也不会改动 Windhawk 设置。真正全屏、会话锁定或自动隐藏任务栏收起时，目标屏幕上的胶囊会隐藏。

## 退出与卸载

从托盘菜单选择“退出”。退出时应用会关闭全部浮层、托盘图标及其创建的 Codex App Server 子进程。

卸载便携版只需先退出应用，再删除解压目录；如果启用过“开机启动”，请先在托盘菜单中取消勾选。

# Codex 额度任务栏浮层使用说明

## 启动

1. 解压 `artifacts/releases/CodexQuotaTaskbar-win-x64.zip` 到一个固定目录。
2. 双击 `CodexQuotaTaskbar.exe`。
3. 胶囊会贴在每个可识别任务栏的工作区一侧；通知区域会出现“Codex 额度”图标。

应用需要 Windows 10/11 x64，以及已使用 ChatGPT 登录的 Codex 桌面应用或 Codex CLI。正式便携包已内置 .NET 10 Desktop Runtime，新电脑无需另行安装 .NET。应用通过本机 `codex app-server --listen stdio://` 读取当前账号额度；如果 Codex CLI 不在 `PATH` 中，会自动查找 Codex 桌面版安装包内的官方可执行文件，并复制到 `%LOCALAPPDATA%\CodexQuotaTaskbar\Runtime\Codex` 缓存后启动。这样既能使用桌面版现有的 ChatGPT 登录，也不会尝试直接执行受 Windows 商店权限保护的文件。

详情中的账号摘要采用三栏玻璃卡：订阅档位使用大写额度名称（服务端返回 `prolite` 时显示 `PRO 5X`，返回 `pro` 时显示 `PRO 20X`）；额外点数显示官方 App Server 返回的 `credits.balance`，无限额度显示“不限”，点数可用但服务端未披露余额时显示“可用”；“订阅有效至”优先使用同一账号有效的网页登录日期缓存，没有时使用本地 Codex 登录信息，必要时再向 ChatGPT 订阅接口只读补全。

有效期下方会标明来源和更新时间；如果刷新失败但仍有上次结果，会标记为缓存。该日期表示目前可读到的订阅有效截止时间，自动续费后可能延长，不代表当天一定取消订阅，也不是额度的重置时间。

## 操作

- 悬停胶囊：不再弹出系统白色提示框；额度、重置时间和数据状态请在详情卡中查看。
- 单击胶囊：打开或关闭详情卡。
- 右击胶囊或托盘图标：打开液态玻璃控制菜单，可立即刷新、检查更新、网页登录订阅、打开 Codex、切换全部任务栏/仅主任务栏、低额度提醒、订阅有效期、自动更新、开机启动或退出。
- 将胶囊移动到桌面边缘后打开详情：详情会自动选择空间充足的一侧，并完整保持在当前屏幕可用区域内。
- 发布包、可执行文件和托盘统一使用原创“双额度轨道”图标，不使用 OpenAI 标志。
- 详情卡中按 `Esc`：关闭详情卡。

账号没有独立的 5 小时窗口但有 7 天额度时，上方“5 小时”暂时复制 7 天百分比，下方仍显示 7 天；详情显示服务端实际返回的额度窗口。

## 订阅有效期

- 默认开启。托盘菜单中的“订阅有效期”可随时关闭；关闭后停止增强读取并关闭网页登录窗口，正常额度与额外点数继续刷新。主动打开网页登录入口会启用此功能。
- 没有有效网页日期缓存时，本地登录信息中已有有效订阅日期就直接显示，更新时间对应登录文件修改时间；日期缺失或已过期才使用现有访问令牌查询固定的 ChatGPT HTTPS 订阅接口，在线结果显示查询时间。
- 原有本地读取组件不读取其他浏览器 Cookie、系统密钥环或进程内存，不读取刷新令牌字段，不修改或另存凭据，也不把凭据写入日志；不会主动刷新登录令牌。
- 服务拒绝查询时，可点击详情“网页登录 · 更新订阅日期”或托盘“网页登录订阅”。在可见的官方页面登录与 Codex 相同的账号，手动完成验证后点击“已登录，读取订阅”。同一账号的重复别名会合并；未知响应不再被当成登录错误，真实不同的个人/团队工作区仍需核对。
- 网页登录另需 Microsoft WebView2 Runtime；缺失时窗口提供微软官方下载入口，额度岛仍可使用，.NET 无需另装。Google 等登录方可能限制内嵌浏览器，程序不会绕过限制，也不保证私有接口一定提供日期。
- WebView2 使用本机独立目录保留网页登录状态，不导入常用浏览器资料。窗口中的“清除网页登录”清除此独立资料及网页日期缓存，不退出 Codex 或其他浏览器。网页令牌不回传原生应用。
- 网页日期需手动更新，超过 3 分钟标为缓存，到期弃用；普通额度仍按原有 3 分钟周期自动刷新。
- 仅把登录信息保存在系统密钥环的设备可能无法显示有效期；网络不可达、登录过期、服务端未披露日期或私有接口变化也可能导致“未提供”或“暂不可用”。这些状态不会阻断额度获取。登录过期时请在 Codex 中重新登录，再点击“立即刷新”。
- 读取的具体字段、请求范围与数据限制见 [隐私与数据说明](privacy.md)。

## 自动更新

- 默认开启；启动约 15 秒后检查一次，此后每 6 小时检查 `dddeeprog/CodexQuotaTaskbar` 的最新正式 Release。
- 只接受固定仓库、固定 ZIP 文件名和高于当前版本的正式版。
- 下载完成后校验 GitHub SHA-256、压缩包单文件结构和 EXE 文件头；全部通过后才退出当前实例、原位替换并重新启动。
- 更新失败时保留当前版本，后台模式稍后重试，手动检查会显示通知。

## 状态说明

- 银白色：剩余不少于 30%。
- 琥珀色：剩余 10%–29%。
- 红色：剩余低于 10%。
- 中性占位：未登录、当前认证方式无 ChatGPT 额度、协议暂不可用或该行没有数据。
- 降低饱和度：连接中断，正在显示最后一次有效额度。

## 与 Windhawk 共存

应用是独立的任务栏贴边浮层，不注入 Explorer、不修改任务栏 XAML，也不会改动 Windhawk 设置。真正全屏、会话锁定或自动隐藏任务栏收起时，目标屏幕上的胶囊会隐藏。

## 退出与卸载

从托盘菜单选择“退出”。退出时应用会关闭全部浮层、托盘图标及其创建的 Codex App Server 子进程。

卸载便携版只需先退出应用，再删除解压目录；如果启用过“开机启动”，请先在托盘菜单中取消勾选。

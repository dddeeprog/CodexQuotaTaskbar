# 点岛 v0.1.13

点岛将 BongoCat、小白球、额度与任务整合在同一卡片中。小白球保留 32 种随机表情、鼠标视线及 Codex 进程状态；BongoCat 使用固定的 Live2D standard 模型。可选键鼠互动处理本地瞬时物理状态，不转换、保存或上传输入文字，首次安装默认关闭。

- 新消息通过顶部紧凑提醒行展示，10 秒后收回；猫头感叹号保留未读提示。点击感叹号只清除点击时已收到的提醒，新到消息继续累计，历史消息不删除。本版移除回复框及提醒行内重复的已读按钮。
- 底部有效重置预告平滑展开、失效后收回；可见时小白球变绿，收回后恢复白色。预告来自第三方公告跟踪，并非本账户额度到账确认。
- 右键菜单在固定宽度内进入分类页并返回，保留正常滚动、细滚动条及淡出。左右弹出面板字重、间距和过渡统一，收敛切换时重复入场的触发路径。
- 详情页提供本地保存的网站快捷图标。支持添加、删除、更换本地图标与恢复自动图标；自动获取失败仍可使用字母占位，现有安全网络边界保留。手动图片等比裁切填满圆角图标区域，不修改原图。
- 感叹号悬浮提示缩短为累计数量，菜单鼠标悬浮不再出现明亮蓝色描边，键盘导航仍有中性焦点提示。

## 组件与数据

BongoCat renderer 含单独许可的 Live2D Cubism Core；点岛主体继续按 GPL-3.0 提供。安装版、便携版和自动更新共用 Core 专用首次使用确认：仅主动启用后展示条款，未确认或拒绝时保留小白球与其他功能，不自动开启键鼠互动。在“外观与互动 → Core 组件条款 → 开源与第三方许可”中可阅读声明、保存完整离线许可集合。完整组件声明与来源见 `THIRD_PARTY_NOTICES.md`。

更新应保留设置、网站与自选图片、历史消息、读标记及遗留草稿；不迁移为新的发送操作、不自动清除提醒。更新前请正常退出正在运行的点岛。兼容旧更新器的 ZIP 文件名与根目录单 EXE 结构保持。

## 验证边界

右键切换重复入场的合成竞态已验证；用户现场的概率性双弹未完整重现，因此不宣称已证明唯一现场根因。消息与重置动画的隔离帧时间结果不等于真实磨砂窗口下的 144 Hz 保证。点岛本地未读与 dot 网页已读不作可靠同步承诺。

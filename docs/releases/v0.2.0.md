# 点岛 v0.2.0

本次正式发布整合原有小弹窗与五项可靠性改进，并撤销未解决菜单重复弹出的菜单首帧临时试修及限量诊断。

- 保留原有菜单/详情小弹窗入场、退出、同宽分页及减少动画设置；恢复临时首帧试修前的显示流程，不将重复弹出问题标为已修复。
- 更新流程增加包身份校验、就绪握手与失败恢复边界；状态不确定时保留恢复材料，避免重复执行安装。
- 防止旧额度请求覆盖新状态、已消费的重置预告重新出现。
- 提示隐藏后恢复时保持相位，避免重播和过期状态残留。
- 增加有界脱敏诊断与本地故障信息导出，并将诊断快照合并到后台写入。未据此宣称整机内存、耗电或性能获益。

v0.1.16已有的三色自动提示继续保留：红绿单行、金色倒计时和完整日期两行，真实额度回升与首次提示期限规则保持。取消的每日收工交接及Git工作台入口不包含在本版。临时菜单时序采集代码和开关不进入本版，历史证据仅本机保留。

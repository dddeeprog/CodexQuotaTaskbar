## 主要更新

- 右键菜单新增「材质透明度」滑块，支持 0%–100%：默认 0% 不透底，拖动时实时预览，停止调整后自动保存，重启后保留设置。
- 额度岛、详情、会话、菜单及角标外壳统一应用透明度，文字、图标和原有动画不被淡化；高对比度或系统关闭透明效果时优先使用系统实色。
- 修复调整透明度后点击其他菜单开关可能恢复旧设置的问题；快速连续调整及退出前的最终值会按顺序保存。
- 额度岛增加「最近重置」摘要，详情查看最近三条公共重置公告，区分常规与备用重置。
- 公告优先显示 Codex Resets 网站自身的中文译文，不显示 X 推文入口或正文网址，保留中文来源署名。
- 右键菜单操作文字与会话标题统一字体、字号和字重；详情隐藏滚动条但保留滚轮操作，精简公告区重复说明。
- 菜单新增设置后可自适应屏幕高度，小屏幕仍可滚动访问全部选项。

## 使用与限制

- Windows 10/11 x64；下载 `CodexQuotaTaskbar-win-x64.zip`，解压运行 EXE。便携包已包含 .NET 10，无需另装 .NET。
- 可通过托盘「检查更新」升级，也可等待自动更新。已有设置会保留；旧配置没有透明度字段时默认不透明。
- 可选的 ChatGPT 网页登录仍需要 Microsoft WebView2 Runtime。订阅日期查询受登录方、私有接口和账号状态限制，不保证所有账号都能读取。
- 普通额度每 3 分钟兜底刷新；公共重置公告独立每 15 分钟检查，也可手动刷新。公告请求不携带账号、凭据或会话正文。
- 公共公告不代表个人额度已经到账，备用重置需在 Codex 中手动使用；本应用不领取或预测重置。
- 中文译文不可用时保留已有译文，或明确标注原文；公告断网时显示缓存或暂不可用，不影响额度读取。
- 材质透明度仅调节背景浓淡，不承诺真正的桌面壁纸模糊。保持独立 WPF 浮层，不注入 Explorer，可与 Windhawk 共存。

# 点岛 v0.2.2

本版新增全屏显示开关，并补齐网站“可能重置”信号的黄色提示。

- 右键菜单“功能设置”新增“全屏时自动隐藏”。默认开启，关闭后全屏时也显示点岛；选择会保存，已有配置继续保留。
- 识别 Codex Resets 网站的有效观察信号，不再只接受某一级别，也不按概率设置本地显示门槛。信号进入黄色光环和小弹窗，文字显示“可能重置”和观察截止时间；悬停可查看来源及估计概率。
- 正式预告继续显示“即将重置”；可能性信号与确定时间预告分开呈现，不代表本账号额度已恢复。观察信号到期或网站撤回后清除。
- 网站公开观察信号不再随本机额度连接重建而消失。

## 下载与升级

- `CodexQuotaTaskbar-Setup-win-x64.exe`：标准当前用户安装包。
- `CodexQuotaTaskbar-win-x64.zip`：便携包及正式自动更新载荷，根目录仅主EXE。
- `DianDao-BongoRuntime-win-x64.zip`：沿用已审阅的可选组件，基础包不捆绑Core；启用仍需用户主动同意条款。
- `SHA256SUMS.txt`：以上三个包的SHA256校验。

Windows x64，内置.NET 10 Desktop Runtime。升级保留原有配置与自动更新选择。

## 主要更新

- 新增中文安装包：支持安装目录、开始菜单、可选桌面快捷方式和 Windows 卸载入口，内置 .NET，无需管理员权限。
- 新增「一体面板」，额度与会话共用一个紧凑窗口；右键外观菜单可随时切回「经典气泡」，选择自动保存。
- 缩小经典会话气泡的宽度，修复屏幕边缘拖动时岛与会话错位、来回跳动的问题。
- 重做轻量右键菜单，将外观与偏好设置分组，使用勾选状态和系统 UI 字体。
- 左键详情明确划分账户与订阅、额度、重置公告三个区域；保留固定底部操作，精简重复说明。
- 修复部分缩放下分隔线被像素取整而消失的问题，提高细线可见性。
- 修复打开右键子菜单时可能因模糊组件延迟回调而退出的问题；子菜单保留统一底色与透明度。

## 下载与升级

- **安装版**：`CodexQuotaTaskbar-Setup-win-x64.exe`，适合希望使用快捷方式和系统卸载入口的用户。
- **便携版**：`CodexQuotaTaskbar-win-x64.zip`，解压后运行 EXE。已有自动更新仍使用这个 ZIP，无需改为安装版。
- 两者均支持 Windows 10/11 x64，并包含 .NET 10。可选的订阅网页登录仍需要 Microsoft WebView2 Runtime。
- 安装前退出额度岛；升级保留个人设置与网页登录资料，卸载也不会清除这些资料。
- 安装包未配置代码签名，Windows 可能显示未知发布者。请只从本仓库正式发行页下载，不要关闭系统安全保护。

## 保持不变

- 额度每 3 分钟兜底刷新；公共重置公告独立每 15 分钟检查。
- 保留透明度设置、Codex/Spark 来源、订阅计划和额外点数；订阅日期仍受账号与服务接口限制。
- 独立 WPF 浮层，不注入 Explorer，可与 Windhawk 共存。材质不承诺真正的桌面壁纸模糊。
- 公共重置公告不是个人到账确认，应用不会自动领取重置。

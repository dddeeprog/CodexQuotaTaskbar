# 点岛 v0.2.1

本版整合已在本机试用的重置卡功能与金色提示排版调整。

- 左键详情显示个人重置卡数量和有效期，每张可辨认明细右侧提供“使用重置卡”。没有可用卡时只显示“当前没有可用重置卡”。
- 移除重置卡区域的来源、更新时间和闲置条件说明，取消独立刷新按钮，统一使用面板底部“刷新”。缓存、未知状态和真实操作结果仍明确提示。
- 使用前核对当前账号及工作区并二次确认；请求先在本机保存，防止重复发送。结果不明时不会自动重试，可明确选择沿用上次请求编号。实际消耗的卡由服务端选择，列表按钮不指定卡ID。
- 金色提示改为单行：“即将重置”居左，“最晚M月d日周X HH:mm”居右；到期后仍等待本账号实际额度恢复。红绿单行、首次预告锁定和提示期限保持。

- 修正猫与白球共存时未计入白球上移的留白，避免部分尺寸下轻微重叠，保持原面板高度。

## 下载与升级

- `CodexQuotaTaskbar-Setup-win-x64.exe`：标准当前用户安装包，保留用户配置。
- `CodexQuotaTaskbar-win-x64.zip`：便携包及正式Release自动更新渠道，根目录仅主EXE。
- `DianDao-BongoRuntime-win-x64.zip`：沿用已审阅的可选组件载荷，基础包不捆绑Core，启用仍需用户主动同意条款。
- `SHA256SUMS.txt`：三个发布包的SHA256。

Windows x64，内置.NET 10 Desktop Runtime。自动更新保持用户原选择。

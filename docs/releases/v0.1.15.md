# 点岛 v0.1.15

## 更新内容

- 本版停用本机项目工作台的菜单入口、启动协调器和快捷键；保留工作台源码及旧设置兼容。额度详情、设置、订阅登录等正常弹窗继续可用。
- 重置预告采用首次有效截止时间锁定，同一轮预告被实际额度回升消耗后不重复出现；绿色额度回升提示保留1小时。预告锁定状态只在当前进程内存保留，已有确认回执继续按账号范围校验恢复。
- 一体面板可在悬停小球时，通过底部区域说明绿色“额度已回升”或红色“重置预告查询失败”。它不是自动弹窗；Dot顶部通知/回复展开、手势操作或空间不足时可能不显示。普通会话列表与Dot顶部扩展是不同区域。
- 预告提示补全本地日期、时区、来源及首次核对时间，避免把后续轮询时间误作首次时间。
- 加强 QQ 截图遮挡识别与浮层恢复，修正猫隐藏缓存、额度详情关闭竞态及点击路由；实际多屏、DPI与第三方截图场景仍需实机验证。
- 调整小球唤醒表情、普通RGB底座亮度和底座边缘呼吸，修正白球抬升及DPI标注；保留原有32表情、白球与猫共存和减少动画设置。
- 多个更新入口共享安装预留状态，减少重复安装请求。
- 新增本地浮层生命周期诊断：默认写入用户数据目录，每个进程快照最多128条，不记录正文、标题、账号或指针坐标，不上传。诊断目录当前没有自动清理或独立关闭开关，详见[隐私与数据说明](../privacy.md#浮层生命周期诊断)。

本版不包含每日收工总结或次日交接功能。

- `SHA256SUMS.txt`：三个发布包的SHA-256校验值。

Windows x64，内置.NET 10 Desktop Runtime；Dot及订阅网页登录需要WebView2 Runtime。GPL-3.0及第三方组件条款不变。产品未配置代码签名，不能将SHA-256校验等同于发布者签名；无需关闭系统安全保护。

本版沿用GitHub正式Release作为自动升级渠道。安装、替换和当前运行实例切换未纳入本轮验收；更新前请正常退出点岛，安装包不清除现有用户设置、消息和已读状态。

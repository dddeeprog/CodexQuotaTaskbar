# 点岛 v0.1.14

## 更新内容

- 白色小球新增普通状态下的同环多色 RGB 渐变底座、呼吸和轻柔漂浮。球底同色柔光随距离衰减，脸部保持白色；实体底座与点击区域不跟着漂移。
- 32 种表情按约 12 秒随机洗牌轮换，每轮完整覆盖、跨轮不连续重复；保留键鼠互动、白球与 BongoCat 共存，减少动态时停止漂浮，隐藏时保留轮播剩余时间。
- 安装期间可明确选择是否同意 Live2D Cubism Core 条款。基础安装包与更新 ZIP 不包含 Core，只有同意后才下载并逐项校验可选固定模型组件；拒绝或关闭保留白球，静默安装不代替同意。
- 新安装同意后应用一体面板、白球与猫共存、3% 透明度、隐藏托盘等预设；升级不覆盖已有配置。Dot 实时接收、键鼠互动和开机启动仍须单独开启。
- 区分第三方预告、本账号额度恢复和预告查询失败：金色预告、绿色恢复提示（1 小时）、红色未恢复失败；查询中不再单独显示蓝色。
- 额度岛按实际返回的额度窗口自适应显示，不再以周额度冒充 5 小时；完善未知、空窗口、缓存和账号切换的处理。
- 检查更新、下载、校验和失败提示统一为原生磨砂窗口，显示进度和可操作的错误原因。
- 简化菜单中的重复 Dot 入口与表情试玩入口，保留白球入口和实时消息提醒；优化通知读取的正文扫描和对象分配，保留消息身份及已读校验。
- 修正小球、猫头提醒和额度面板的输入区域与对齐，保留经典和一体面板布局。

## 下载

- `CodexQuotaTaskbar-Setup-win-x64.exe`：安装版，支持卸载与快捷方式。
- `CodexQuotaTaskbar-win-x64.zip`：便携版，同时供应用自动更新使用。
- `DianDao-BongoRuntime-win-x64.zip`：同意组件条款后由应用自动下载的可选固定模型渲染组件，无需手动解压。
- `SHA256SUMS.txt`：上述三个发布文件的 SHA-256 校验值。

Windows x64，内置 .NET 10 Desktop Runtime。Dot 与订阅网页登录需要 WebView2 Runtime；白球本身使用原生 WPF，不增加浏览器实例。GPL-3.0 及第三方组件条款保持不变；未配置代码签名，Windows 可能显示“未知发布者”，无需关闭系统安全保护。

更新前请正常退出点岛。现有设置、消息和已读状态保存在用户数据目录，安装包不清除它们。

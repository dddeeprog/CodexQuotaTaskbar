# 点岛 v0.1.16

- 一体布局的红、绿、金提示在相应业务状态有效时自动显示，离开小球后继续保留；重复轮询不重复弹出。
- 红色只保留“重置预告查询失败”，绿色只保留“额度已回升”。移除第二行及其空白占高，常规行26DIP，受限空间在原48DIP头部内用14DIP单行显示。
- 金色保留倒计时（到点后等待真实额度恢复）和完整本地日期时间两行；完整行42DIP，受限时头部52DIP。点击金色提示仍打开固定官网，红绿和失效的旧点击不导航。
- 修正金/红绿切换时的空间重新计算及动画保留高度，避免Dot顶部内容、额度和会话计数被错误挤占。
- 真实额度回升确认、绿色首次1小时不延长、首次预告锁定/消费规则、Dot未读和活跃会话数保持。经典布局不新增自动提示；物理空间不足金色最小4DIP增量时隐藏说明并保留业务状态。

仅含本次三色自动提示与单行修复，未包含开发线另存的安装诊断修复或已取消的每日交接功能。预览使用合成状态和真实离屏控件；不将测试伪装成真实账号恢复或网络失败。

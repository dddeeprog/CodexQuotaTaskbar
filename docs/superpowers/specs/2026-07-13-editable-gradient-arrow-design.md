# 可编辑渐变箭头 PPT 设计

日期：2026-07-13

## 目标

新建一份仅含一枚箭头的 PowerPoint 文件。箭头复刻参考图的细长右向轮廓、上下凹口与蓝色渐变，并保持为 PowerPoint 原生矢量形状，可直接调整节点、尺寸、颜色、渐变、位置和透明度。

## 参考图

- 稳定副本：`docs/superpowers/specs/assets/editable-gradient-arrow-reference.png`
- 原始像素尺寸：`110 x 707 px`
- SHA-256：`10E522514EEF1260FBFA1AF77AD01842A224769F77B5B02C2D2596CD65BCBD37`

制作与验收均以该副本为唯一视觉参考。

## 交付物

- 文件名：`可编辑渐变箭头.pptx`
- 单页、16:9、白色背景。
- 页面中央放置一枚纵向占比较高的右向箭头，方便复制到其他演示文稿。
- 箭头高度约 `6.50 in`，宽度约 `1.02 in`；在 `13.333 x 7.50 in` 的页面中水平、垂直居中，四周不裁切。
- 不嵌入参考位图，不使用不可编辑的截图或背景图。

## 形状设计

箭头使用一个闭合的 PowerPoint 自由曲线形状完成：

- 整体高宽比约为参考图的 `6.4:1`。
- 左侧上下边缘以平滑曲线向中部收拢。
- 中部保留上下两个尖锐凹口。
- 右侧为清晰的单一箭头尖端。
- 形状不设轮廓线。

轮廓以形状包围框归一化坐标描述，便于在生成时按任意尺寸缩放：

1. 左上角 `(0.00, 0.00)`。
2. 上侧曲线收拢至 `(0.66, 0.37)`。
3. 垂直上挑至箭头上基点 `(0.66, 0.28)`。
4. 连接右侧尖端 `(1.00, 0.50)`。
5. 连接箭头下基点 `(0.66, 0.72)`。
6. 垂直上收至下侧凹口 `(0.66, 0.62)`。
7. 下侧曲线展开至左下角 `(0.00, 1.00)`。
8. 沿左边界闭合。

实际制作时允许微调曲线控制点，以参考图的视觉轮廓为准，同时保持上下近似对称。

## 填充设计

使用 PowerPoint 原生水平线性渐变，由左向右逐渐增强蓝色：

- 左端：极浅蓝，高透明度，接近白色背景。
- 中段：柔和天蓝，中等透明度。
- 箭头主体：清晰的中蓝，低透明度。
- 右端：略柔和的蓝色，使尖端不显得过重。

建议渐变停靠点：

- `0%`：`#DDEAFF`，透明度约 `85%`。
- `38%`：`#9FC2F2`，透明度约 `45%`。
- `72%`：`#4F8FDE`，透明度约 `8%`。
- `100%`：`#75A9E7`，透明度约 `18%`。

## 制作方式

通过 PowerPoint 原生自由曲线构建闭合轮廓，并设置原生渐变填充。生成过程不把箭头栅格化；最终文件应能在 PowerPoint 中进入“编辑顶点”模式。

## 验收标准

- PPTX 可正常打开，且只有一张幻灯片。
- 幻灯片中只有一枚主要箭头形状，无参考截图残留。
- 箭头方向、比例、凹口和蓝色渐变与参考图视觉一致。
- 箭头可移动、缩放、旋转、编辑顶点并修改渐变。
- 导出预览无裁切、重叠、接缝或异常边框。
- 通过渲染截图对比轮廓和渐变，并检查 PPTX 内部不存在作为箭头主体的位图资源。

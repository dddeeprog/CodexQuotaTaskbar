# 点岛（CodexQuotaTaskbar）

> 点岛 0.1.13。正式下载与校验文件以本仓库 Releases 为准。

一个贴着 Windows 任务栏显示的 Codex 额度小岛。它使用中性的 iOS 风格磨砂外观，不注入 `Explorer.exe`，也不修改任务栏 XAML，因此可以独立运行，并能与 Windhawk 共存。

## 功能

- 在 Windows 任务栏边缘显示 Codex 的 5 小时与 7 天剩余额度，保留经典气泡和一体面板布局。
- BongoCat 与白色小球可在同一卡片共存；小球保留 Codex 会话状态数量、32 种随机表情和眼睛跟随。猫使用固定 standard Live2D 模型，大小可调，不提供任意模型导入。
- 额度和任务列表保持可读；展开最多三行任务，更多任务可滚轮浏览。点击名称可回到对应 Codex 会话，内部 subagent 不计入任务角标。
- 左键详情显示账户、订阅、额度及常用网站图标。网站支持添加、删除、自动或手动图标；重置公告网站仍可作为入口保留。
- 右键主菜单为七个常用入口；外观与功能设置在原菜单同宽换页，顶部返回，不并排展开。保留正常滚动、细滚动条淡出、透明度滑杆及半粗文字。
- Dot 新消息从同一面板顶部短暂伸出紧凑提醒行，10 秒后收回并保留提醒标记。猫头感叹号点击清除当时累计提醒；两种形象均不提供回复框或发送入口。
- 有效重置预告在卡片底部显示一小行，出现/收回有轻量过渡；该行实际可见时白球变绿，隐藏后恢复白色。它是第三方预告，不是本账号重置确认。
- 左右键浮层避开整块主面板，保留原开合过渡、拖动跟随、多屏/DPI、深浅色、高对比及全屏隐藏。减少动态效果时直接切换。
- 托盘和程序图标使用白球双眼角色。界面沿用原生 WPF 磨砂、圆角与细分隔，材质透明度可调，不新增全屏浏览器来显示角色。
- 默认连接本项目 GitHub 正式 Release 自动更新，也可手动检查或关闭。托盘图标可隐藏和恢复；隐藏不影响额度、会话、Dot 后台接收或更新检查。
- 独立运行，不注入 Explorer、不修改任务栏 XAML；不需要 Windhawk，也不要求关闭或修改已有 Windhawk。

## 数据说明

应用通过本机已登录的 Codex App Server 只读获取额度。仅安装 Codex 桌面版时，应用会将桌面包内的官方 Codex 可执行文件复制到自己的本地运行缓存后启动，从而避开 Windows 商店目录禁止外部启动的限制，并继续使用现有 ChatGPT 登录：

- 小岛上方固定显示“5 小时”，下方固定显示“7 天”。
- 如果账号当前没有单独的 5 小时窗口，上方会暂时复制 7 天额度，避免显示空白；详情页仍展示服务端返回的真实窗口。
- 普通 Codex 额度标记为 `Codex`，`codex_bengalfox` 周额度标记为 `Spark`。
- 订阅计划只读取账号响应中的 `planType`，额外点数读取官方 App Server 额度响应中的 `credits.balance`；应用不会读取或显示邮箱。
- “订阅有效至”优先使用同一账号已保存的网页登录结果；没有时读取本地 Codex 登录信息中的订阅时间，缺失或已过期时再通过固定的 ChatGPT HTTPS 订阅接口只读补全。详情仅显示订阅、有效期和额外点数，不再显示来源、更新时间及缓存说明行；失败不影响额度刷新。
- 服务拒绝查询时，可点击详情中的“网页登录 · 更新订阅日期”或托盘“网页登录订阅”。在可见的官方页面手动登录、完成验证后，点击“已登录，读取订阅”。必须与 Codex 登录相同账号；Google 等第三方登录可能限制内嵌浏览器，服务也可能不提供日期。
- “订阅有效期”默认开启，可在托盘菜单关闭。原有本地读取不会写回登录凭据或主动刷新令牌；可见网页使用独立 WebView2 资料目录保留登录状态，不导入其他浏览器数据，也不把网页令牌回传应用。可从窗口中清除网页登录及网页日期缓存。完整读取范围见 [隐私与数据说明](docs/privacy.md)。
- 网页日期只在窗口中手动更新，超过 3 分钟按缓存处理、到期弃用；普通额度仍按原有周期自动刷新。
- 订阅有效期表示服务端披露的当前订阅有效截止时间，不保证订阅会在当天取消；自动续费、账号切换或登录信息尚未更新都可能使它变化。它不是额度重置时间，私有接口变化或仅使用系统密钥环保存登录时也可能暂不可读。
- `prolite` 显示为 `PRO 5X`，`pro` 显示为 `PRO 20X`；这两档对应当前 Codex Pro 的 5 倍与 20 倍额度方案。
- 无法刷新时会保留最近一次数据并标记为陈旧，过期后显示不可用。
- 启动时立即刷新；服务端通知后约 300 毫秒刷新，并且每 3 分钟自动兜底刷新一次。
- 详情“常用网站”只展示网站图标，悬停查看名称和域名，点击用默认浏览器打开。点击“+”输入网址即可添加，默认补 HTTPS，可同时选择本地 PNG/JPEG/ICO 图标；右键可更换图标、恢复自动图标或删除网站。手动图标复制到应用自有缓存并优先显示，后台获取不会覆盖；删除网站不删除用户原图。列表及图标独立保存在本机，重启保留；首次仅包含重置公告网站，主动删空后不会重新添加。自动提取受网络安全检查约束，失败则显示域名首字母，不读取浏览器书签或历史，也不使用第三方 favicon 服务。现有公共重置数据读取和桌面底部预告小行独立保留。
- 任务浮窗最下方用一小行显示 Codex Resets 的已安排重置预告，仅包含约多久后重置和本地预计时间。没有安排、截止不明、已过期、断网或超过 3 分钟未确认时整行隐藏，不保留占位；来源和核对状态放在提示中。独立约每 60 秒条件读取公开状态接口，倒计时复用本地计时器按分钟更新，不增加浏览器，不改变浮窗宽度，不将预告当作本账号到账确认。
- 会话状态每 2 秒核对一次。因为独立 App Server 无法读取另一个桌面进程的内存状态，应用只读监听 `.codex/sessions` 中最近修改的任务事件，并从 `.codex/session_index.jsonl` 读取 Codex 已生成的任务名称；不读取终端内容，也不上传会话正文。
- 会话显示优先级为：需要输入、任务受阻、可以查看、正在运行；应用启动前已经完成的历史任务不会突然显示为新任务。刚完成的任务保留 30 秒，从点岛打开查看后立即移除；Codex 桌面端没有可供第三方读取的“已查看”回执，因此直接在 Codex 中查看时由 30 秒窗口自动清理。

## 直接使用

系统要求：Windows 10/11 x64，以及已经使用 ChatGPT 登录的 Codex 桌面应用或 Codex CLI。安装版和便携包均内置 .NET 10 Desktop Runtime，新电脑无需另行安装 .NET。

可选的订阅网页登录和 Dot 消息功能需要 Microsoft WebView2 Runtime。右上角表情小球本身使用 WPF 原生矢量绘制，不需要浏览器运行时。

### 白球与 BongoCat

- 右键“外观与互动”管理显示样式、猫显示及尺寸、互动开关、减少动态和透明度。白球与猫共存，不再用互斥外观切换来隐藏另一角色。
- 小球旁的数字表示进行中与等待中的 Codex 会话总数，不包括已完成任务；悬停可查看分类。拖动仍移动整块卡片。
- 32 种表情约每 6 秒按随机洗牌切换，每轮完整覆盖、跨轮不连续重复，不按任务正文选表情。睁眼表情保留鼠标方向跟随，闭眼不强画瞳孔。
- 白球由 [Grok Ball](https://github.com/tycoding/grok-ball) 固定配置与眼形移植为原生 WPF；保留原生粒子/彩带适配，不为表情启动 WebView2，不承诺与 SVG 逐像素一致。
- BongoCat 的模型求值、动作与渲染在本地独立 renderer 中运行，再将像素帧呈现在同一卡片；不是启动另一份上游应用。仅使用随产品交付的固定 standard 模型。
- “跟随键盘敲击”默认关闭。开启后仅在内存处理受支持物理键的按下/松开及鼠标即时状态，驱动本地动作；长按保持、重复按下不交替，松开回退到仍按住的上一键。它不识别文字、不记按键历史、不上传输入，也不增加管理员权限、后台服务或自启动项。
- 隐藏、锁屏、减少动态、停用或退出时清理瞬时输入与相关渲染资源。不同设备的内存/CPU表现不同，不保证帧率或固定占用。
- Live2D Cubism Core 是单独许可的组件。可在右键菜单“外观与互动 → Core 组件条款”主动查看完整条款并选择是否使用；下载、安装或更新不代替确认，未确认或拒绝时保留白球及其余功能。该窗口的“开源与第三方许可”页可阅读 GPL 与组件声明，并将内置的完整许可证集合保存为 ZIP。操作不会自动开启键鼠互动，也不删除已有设置、消息或草稿。

### Dot 消息

- 右键开启“Dot 实时接收”后，通过官方 Dot 网页保持连接；初次同步不提醒历史消息。连接、登录与官网结构变化仍可能影响接收。
- 新消息在同一卡片顶部向上伸出一小行，不抢键盘焦点、不替换任务区；约 10 秒后收回。顶部和底部提示均遵守减少动态设置。
- 收起不等于已读。猫头感叹号只在有本机累计提醒时显示，悬浮提示为“有 N 条新消息 · 点击清除提醒”；接收就绪时，点击会确认点击瞬间已有的整批提醒并清零，之后新到消息重新累计，历史消息不删除。该状态重启保留，不声称与 Dot 网页已读同步。
- 提醒条没有另一个“标为已读／全部已读”按钮；猫球共存及白球回退均不再提供回复框或发送入口。既有草稿和待确认发送证据不会因移除入口而被自动删除、回填或重发。
- 关闭提醒只改变呈现；关闭实时接收或退出点岛才释放消息子进程及浏览器资源。登录/验证由用户主动打开官方网页完成，不绕过验证。
- 实时接收使用单个隐藏网页桥接，并不是轻量直连 API；保留低内存目标、有限缓存和独立可退出进程，不承诺内存上限。角色自身不使用这个浏览器。

### 内存与绘制

- 默认使用 WPF 软件绘制，减少独立小窗口加载显卡驱动与编译缓存的开销；白色小球、32 种表情、磨砂材质和动画仍保留。不同设备的收益不同，软件绘制可能增加 CPU 开销；如出现动画卡顿，可退出后使用 `CodexQuotaTaskbar.exe --hardware-rendering` 启动恢复硬件绘制，不改写个人设置。
- .NET 使用 `System.GC.ConserveMemory=7` 的节省内存策略，不设置硬性内存上限，不定时强制清空工作集。
- 会话仍每 2 秒核对，但内容不变时不再重建界面；会话解析缓存限定为最近 20 个任务，淘汰后仍保留关闭状态。首次尾部扫描跳过残缺日志行时按字节查找换行，避免为丢弃的长行分配大字符串。

**安装版**：双击 `CodexQuotaTaskbar-Setup-win-x64.exe`，按中文向导选择安装目录与可选桌面快捷方式。默认安装到 `%LOCALAPPDATA%\Programs\CodexQuotaTaskbar`，无需管理员权限；自动添加开始菜单与 Windows“已安装的应用”卸载入口。安装或卸载前请从托盘退出点岛，包括正在运行的便携版。卸载保留个人设置和网页登录资料，只清理程序、快捷方式及指向本安装路径的开机启动项，不修改 Codex 或 Windhawk。

**便携版**：

1. 解压 `CodexQuotaTaskbar-win-x64.zip`。
2. 双击 `CodexQuotaTaskbar.exe`。
3. 左键点击小岛查看详情；按住并拖动可调整位置；右键打开液态玻璃托盘菜单。详情会根据小岛当前所在的屏幕边缘自适应定位。

两种版本都不会自动写入开机启动。需要时可在托盘菜单中手动开启。从便携版迁移后若曾启用开机启动，请在安装版中关闭再开启一次，使启动路径指向安装版；设置和登录资料共用，不需重新配置。

## 自动更新

- 启动约 15 秒后检查一次，此后每 6 小时检查一次；仅安装 GitHub 上标记为正式版且高于当前版本的 Release。
- 下载目标固定为 `dddeeprog/CodexQuotaTaskbar` 仓库中的 `CodexQuotaTaskbar-win-x64.zip`。
- 安装前同时校验 GitHub 返回的 SHA-256、ZIP 单文件结构和 Windows EXE 文件头；校验失败不会替换当前程序。
- 更新完成后小岛自动退出、原位替换并重新启动，已有设置与开机启动路径不变。
- 安装版同样使用上述便携 ZIP 原位更新主程序，无需重新运行安装向导；卸载入口保持有效。Windows“已安装的应用”中的版本号以最近一次运行安装包时为准，实际程序版本以托盘菜单为准。
- 功能设置中的“自动更新”可关闭后台检查，“检查更新”可随时手动触发。请求超时或包校验失败不会永久结束后续检查；手动结果区分无新版与检查失败，隐藏托盘时仍可看到最终结果。

## 构建

源码构建使用仓库 `global.json` 中指定的 .NET SDK。PowerShell 中运行：

```powershell
.\build.ps1 -Target Build -Configuration Release
.\build.ps1 -Target Package -Configuration Release
```

生成的文件位于：

- 可运行目录：`artifacts/host-publish/Release/`
- 便携 ZIP：`artifacts/releases/CodexQuotaTaskbar-win-x64.zip`

构建安装版需额外准备 [Inno Setup 6.4 或更高版本](https://jrsoftware.org/isdl.php)。使用标准安装路径、将 `ISCC.exe` 加入 PATH，或设置 `ISCC_PATH` 后运行：

```powershell
.\build.ps1 -Target Installer -Configuration Release
# 也可显式指定编译器路径：
.\build\package-installer.ps1 -IsccPath 'C:\Tools\Inno Setup 6\ISCC.exe'
```

安装包输出至 `artifacts/installers/CodexQuotaTaskbar-Setup-win-x64.exe`，使用独立暂存目录，不覆盖便携发行 ZIP 或正在运行的本机程序。目前未配置代码签名证书，Windows 可能显示“未知发布者”；不应关闭系统安全保护。

运行无账号依赖的演示模式：

```powershell
.\artifacts\host-publish\Release\CodexQuotaTaskbar.exe --demo
```

## 验证

完整验证会执行托管测试、原生桥接测试、边界扫描和发布包检查；需要 Visual Studio C++ 构建工具与 CMake：

```powershell
.\build.ps1 -Target Verify -Configuration Release
```

网页登录读取脚本另有不使用真实账号的 Node.js 测试：`node --test tests/browser-subscription-reader.test.mjs`。

## 项目结构

- `src/CodexQuotaTaskbar.Core`：额度模型、解析与投影逻辑。
- `src/CodexQuotaTaskbar.Host`：正式 WPF 浮层、详情卡、托盘和 Codex 数据源。
- `src/native`、`tools/CodexQuotaTaskbar.CompatibilityProbe`：保留的兼容性诊断与验证工具，不进入正式 Host 发布包。
- `tests`：单元测试、原生测试与安全边界检查。
- `docs/使用说明.md`：更详细的日常使用说明。
